EVENT MARKETING & INTEGRATIONS

(Capabilities, 3rd-Party Platforms, UX & Feature Strategy)

1. CORE EVENT OBJECT (FOUNDATION)

Every event in your app should support:

Event name, description, category

Date(s), time(s), timezone

Venue (physical, virtual, hybrid)

Capacity limits

Ticket types (paid, free, comp)

Promo rules

Social + calendar distribution

Attribution & analytics

Key UX principle:

Events are marketing assets, not just calendar entries.

2. TICKETING & EVENT PLATFORM INTEGRATIONS
2.1 Eventbrite (HIGH PRIORITY)

Why

Best API support

Widely used

Free + paid events

Promo codes & comp tickets

Check-in support

Capabilities to integrate

Create/manage events

Sync ticket inventory

Issue promo codes

Generate 100% off / comp tickets

Pull attendee data into CRM

UX ideas

“Sync with Eventbrite”

“Mirror event + tickets”

“Import attendees as leads”

2.2 Ticketmaster (LIMITED, ENTERPRISE)

Reality check

API access is restricted

Often requires approval

More useful for promotion, not management

Use case

Promote major concerts / venues

Affiliate-style promotion

Link-out tracking

UX

“Featured Events”

“Affiliate ticket links”

Conversion tracking only

2.3 Other Ticketing Platforms (Nice-to-have)

Universe

Tito

Splash

Eventcube

Brown Paper Tickets

Design recommendation

Use a generic ticketing adapter layer so platforms can be swapped without UI changes.

3. FREE TICKETS, GIVEAWAYS & PROMOS (CRITICAL)

Your app should natively support:

🎟 Free Tickets / Comp Access

100% discount codes

Invite-only tickets

Limited-quantity giveaways

Role-based access (VIP, press, staff)

Important UX

“Give away tickets” ≠ “free event”

Must support controlled free access

🎁 Giveaway Campaigns

Examples:

“First 100 signups”

“Refer a friend”

“Email subscriber exclusive”

“Social share unlocks ticket”

Integrations

Email campaigns

Social sharing

Referral tracking
