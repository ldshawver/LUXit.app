Security & Compliance

Enterprise-grade security.
Built in, not bolted on.

Every layer of LUX is designed with security, data protection, and compliance in mind. Your data, credentials, and brand reputation are protected by default.

Encrypted Secrets Vault

All API keys, OAuth tokens, and third-party credentials are stored in a centralized, encrypted vault with per-company isolation. No more scattered credentials in config files.

Secure Authentication

OAuth 2.0 authentication supporting Google, GitHub, Apple, and email sign-in. JWKS-based JWT signature verification ensures token integrity and prevents forgery.

Emergency Controls

Instant emergency stop halts all automation across the platform. 27 feature toggles with safe-off defaults let you control exactly which capabilities are active.

Content Approval Queue

Mandatory review workflow for all marketing content — AI-generated and manual. Nothing goes live without explicit human approval. Complete audit trail on every action.

CSRF Protection

Every form submission and API call is protected with CSRF tokens. Cross-site request forgery attacks are blocked at the framework level across all endpoints.

Audit Trails

Immutable logging of all critical actions: content approvals, stage changes, data modifications, and system access. Full accountability and traceability.

Architecture

Security at every layer

Defense in depth: from the network edge through authentication, authorization, data access, and content delivery.

Network
HTTPS/TLS encryption, proxy middleware, rate limiting

Application

Content

Monitoring
AI-powered diagnostics, system health checks, auto-repair engine
